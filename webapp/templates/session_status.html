How the login works

This app runs on a host with an ephemeral disk — the saved session file disappears whenever the server restarts. Rather than needing a manual upload each time, the server signs in by itself.

  1. Set the account secrets once. In your Hugging Face Space: Settings → Variables and secrets. Use a dedicated capture account, never a personal one. 
    X_USERNAME   the @handle (without the @)
X_PASSWORD   its password
X_EMAIL      the account's email — X asks for it on unfamiliar logins
X_TOTP_SECRET  only if 2FA is on (simpler: turn 2FA off on this account)
  2. That's it. The server signs in at startup and again whenever a report finds the session missing or rejected.
  3. Optional fallback. You can still generate the file by hand and place it at {{ sessions_dir }}/x_state.json: 
    python save_login.py x
    On an ephemeral host this is lost on restart, so the secrets above are the durable answer.
